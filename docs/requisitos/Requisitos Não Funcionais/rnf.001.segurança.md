# Segurança

**COMO** usuário do sistema,    
**QUERO** informar usuário e senha para acessar o sistema,  
**PARA** garantir que apenas pessoas autorizadas utilizem a aplicação.

**Critérios de aceitação:**

- O sistema deve exibir tela de login.
- O usuário deve informar usuário e senha válidos.
- O acesso deve ser negado quando as credenciais forem inválidas.
- O sistema deve permitir acesso somente após autenticação bem-sucedida.
