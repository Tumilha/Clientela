# Velocidade

**COMO** operador de caixa,     
**QUERO** registrar vendas rapidamente,   
**PARA** agilizar o atendimento ao cliente sem atrasos.  

**Critérios de aceitação:**

- O registro de uma venda deve ser concluído em poucos segundos.
- O sistema não deve travar durante o processo de venda.
- O sistema deve responder às ações do usuário de forma fluida e estável.
