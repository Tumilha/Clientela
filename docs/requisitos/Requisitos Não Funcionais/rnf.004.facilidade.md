# Segurança

**COMO** funcionário,    
**QUERO** utilizar uma tela de vendas simples e intuitiva,  
**PARA** realizar operações sem necessidade de treinamento avançado.

**Critérios de aceitação:**

- A tela de vendas deve possuir layout organizado e fácil de entender.
- As funções principais devem estar visíveis e acessíveis.
- Um funcionário novo deve conseguir registrar uma venda sem dificuldades.
- Os campos e botões devem possuir identificação clara.
