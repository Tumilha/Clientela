# Acesso

**COMO** gerente/dono,    
**QUERO** visualizar os relatórios financeiros do sistema,  
**PARA** acompanhar o desempenho financeiro da empresa.

**Critérios de aceitação:**

- Apenas usuários com perfil de gerente/dono podem acessar os relatórios financeiros.
- Funcionários sem permissão não devem visualizar essa funcionalidade.
- O sistema deve exibir mensagem de acesso negado para usuários não autorizados.
