# Alertas   

**Como** gestor de estoque,  
**Quero** receber alertas quando um produto estiver próximo de acabar,   
**Para** realizar a reposição antes que falte mercadoria.    

**Criterios de Aceitação:**

 - O sistema deve monitorar a quantidade disponível de produtos.    
 - O sistema deve emitir alerta quando o estoque atingir o limite mínimo definido.  
 - O alerta deve ser exibido ao usuário responsável.
