# Caixa

**Como** operador de caixa,  
**Quero** abrir e fechar o caixa diariamente,    
**Para** controlar o fluxo financeiro do estabelecimento.    

**Criterios de Aceitação:**

 - O sistema deve permitir registrar o valor inicial do caixa.  
 - O sistema deve calcular automaticamente o saldo final.   
 - O sistema deve gerar um relatório de fechamento diário.
