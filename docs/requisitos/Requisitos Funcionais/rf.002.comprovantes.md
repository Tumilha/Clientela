# Comprovante   

**Como** cliente,    
**Quero** receber um comprovante após cada compra,   
**Para** ter um registro da transação realizada.

**Criterios de Aceitação:**

 - O sistema deve gerar um comprovante ao finalizar a venda.   
 - O comprovante deve conter data, hora, produtos, valor total e forma de pagamento.    
 - O comprovante pode ser impresso ou enviado digitalmente.
