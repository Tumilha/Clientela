# Vendas    

**Como** operador de caixa,  
**Quero** registrar vendas em tempo real e receber pagamentos via PIX cartão ou dinheiro,    
**Para** concluir as transações de forma rápida e segura.    

**Criterios de aceitação:**

 - O sistema deve permitir selecionar produtos para venda. 
 - O sistema deve calcular automaticamente o valor total.  
 - O sistema deve aceitar PIX, cartão e dinheiro.  
 - A venda deve ser registrada imediatamente após a confirmação do pagamento.
